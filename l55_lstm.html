The LSTM cell: a memory the gradient can travel along

An LSTM keeps a cell state that is updated by addition, not by being pushed through a weight matrix and a squashing function. The gradient passed back along the memory is just the forget gate — so memories, and their learning signal, can last.

What to notice

c = 0.8, f = 0.9, i = 0.2, g = 0.5, o = 0.7: new cell 0.72 + 0.10 = 0.82; output 0.7 × tanh(0.82) = 0.473. Gradient back along the memory: 0.9 per step (Math Box 55.1).

f = 0.99 over 50 steps keeps 0.61 of the signal; f = 0.9 keeps 0.005 — small, but about twelve orders of magnitude more than the plain RNN’s 10⁻¹⁵. The network learns when to set f near 1 (remember) and when to lower it (forget). The additive path is the same idea as ResNets and the transformer’s residual stream (Chapters 50, 55, 73).
