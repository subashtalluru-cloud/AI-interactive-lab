Speculative decoding: guess ahead, check in one pass

A small draft model proposes k tokens; the large model checks them all in a single pass, keeps the agreed prefix and adds one token of its own. The output is exactly what the large model would have written — only faster.

What to notice

With k = 4: α = 0.6 gives about 2.3 tokens per large pass, α = 0.8 about 3.4 (Math Box 105.1). Predictable text — boilerplate, code, template phrases — accepts more; genuinely uncertain continuations accept less.

Longer drafts help only while α is high: each extra token must survive every earlier one, so returns fall off as αᵏ shrinks, while the drafting cost keeps rising. The real speed-up is tokens per pass divided by (1 + k × draft cost).
