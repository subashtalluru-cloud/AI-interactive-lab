What to notice

With the book's values, token 3 gives 62% of its attention to token 3 and 31% to token 2: its query aligns best with those keys. The output for each token is the weighted average of the value vectors, so token 3's output moves towards V₃.

Switch the causal mask on. Token 1 can now see only itself — its output becomes exactly V₁ — and token 2 splits between tokens 1 and 2. Token 3's row is unchanged, because it could already see everything before it. This one change is what turns an encoder into a generator that can be trained on every position at once.

Turn off the √dₖ division, then make the vectors larger. Scores grow with dimension, the softmax saturates, and attention collapses onto a single token — the problem the scaling factor exists to prevent.
