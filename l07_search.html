Five ways to search a map

The same small road map, searched five ways. Breadth-first counts steps, depth-first follows one corridor, uniform-cost tracks cost paid, greedy chases the heuristic, and A* adds cost paid to cost estimated. Step through and compare what each expands and what route it returns.

What to notice

Breadth-first returns S–B–G: two steps, cost 10. Uniform-cost and A* return S–A–B–C–G, cost 7. A* expands S, A, B, C, G with f = 6, 6, 6, 6, 7 (Math Box 7.1).

Set h(B) = 9 — an overestimate, since B is really only 4 from the goal. A* now shuns B and returns a worse route: an optimistic heuristic can delay search but never deceive it; a pessimistic one can. The heuristic is knowledge, and learning heuristics from data is where search met machine learning (Chapters 5, 7, 64).
