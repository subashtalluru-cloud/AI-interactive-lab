Memory for an assistant: everything, summaries, or retrieval?

After months of use, an assistant has far more history than it can read on every request. Each memory strategy trades cost against the chance of forgetting something that mattered.

What to notice

50 sessions of 3,000 tokens: everything = 150,000 tokens; summaries = 10,000; a 300-token profile plus 5 retrieved 200-token memories = 1,300 — about 1% of the full history (Math Box 129.1).

Cheaper strategies risk missing the allergy mentioned once in session 12. The readout estimates that risk from the recall and summary-retention settings, which are illustrative assumptions. Memory is a retrieval problem with the same recall–precision trade-offs as Chapters 21 and 126 — applied to a person’s history, with the privacy duties that brings.
