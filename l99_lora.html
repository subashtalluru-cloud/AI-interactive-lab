LoRA: learning a change in a few directions

Instead of learning a full update ΔW to a d × d weight matrix, LoRA learns two thin matrices B (d × r) and A (r × d) and uses ΔW = BA. The update can only push outputs along r directions — and that turns out to be enough for most adaptation.

What to notice

For d = 4,096 and r = 8: 16,777,216 parameters for a full update against 65,536 for LoRA — 256 times fewer. Four attention matrices in 32 layers: about 8.4 million trainable parameters, 0.12% of a 7B model.

The saving is 2r/d, so it grows with model width. The trained adapter is tens of megabytes; one frozen base can serve many adapters. After training, BA can be added into W once, so the adapted model runs at the original speed (Chapter 99).
