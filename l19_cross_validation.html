How much does one validation split tell you?

A model’s true error is fixed, but any estimate of it comes from a finite set of cases. A single validation split gives one draw; k-fold cross-validation gives several, and their spread shows how shaky the number is.

What to notice

The book’s five folds — 0.12, 0.18, 0.10, 0.15, 0.20 — average 0.15 with a spread of about 0.04. A single split would have reported just one of those numbers, and you would not know whether it was lucky (Math Box 19.1).

With 200 cases and a 15% error, single 40-case splits range widely; cross-validation narrows the estimate, because every case is used for evaluation once. What it cannot fix: if hyperparameters are tuned on the cross-validation score, that score becomes optimistic — keep a final test set nobody touches (Chapter 19). (This simulation treats each fold’s model as equally good; real folds also vary in the model trained.)
