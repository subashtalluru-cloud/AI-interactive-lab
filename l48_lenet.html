A LeNet-style network, layer by layer

Follow a 32 × 32 image through convolution, pooling and fully connected layers. Two formulas do all the work: the output-size rule and the parameter count (k·k·C_in + 1)·C_out. Change the architecture and see where the parameters go.

What to notice

Book’s network: 156 + 2,416 + 48,120 + 10,164 + 850 = 61,706 parameters; shapes 28 → 14 → 10 → 5, flattening to 400 (Math Box 48.1).

Convolutional layers have few parameters however large the image, because the same small kernel is reused everywhere; the fully connected layer after flattening holds most of them. Modern CNNs replace it with global average pooling for exactly this reason (Chapters 45–50).
