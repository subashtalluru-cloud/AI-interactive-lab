Where a transformer’s parameters live

Each block holds an attention sublayer (four d × d matrices, however many heads) and a feed-forward network (two d × 4d matrices). Add the embedding table and you have almost the whole count: about 12Ld² + Vd.

What to notice

d = 512: per head 98,304; 8 heads 786,432; plus W_O 262,144 = 4d² = 1,048,576. The FFN adds 8d² = 2,097,152, so a block is 12d² ≈ 3.15 million, two-thirds of it in the FFN (Math Boxes 72.1, 73.1). The GPT-3 preset gives about 175 billion.

Changing the number of heads changes nothing in the count: heads partition the same projections. The attention patterns are not parameters at all — they are computed afresh for every input. Memory at 16 bits is 2 bytes per parameter; training with Adam needs roughly 16 (Chapters 72, 73, 81, 98). Real models differ in details (gated FFNs, grouped-query attention, tied embeddings), usually by a few percent. The 7B-class preset gives 6.57 B; Chapter 81’s 6.74 B counts that model’s gated FFN (three matrices of width 11,008) and a separate output layer of V × d.
