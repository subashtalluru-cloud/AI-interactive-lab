When prompting is the wrong tool

If a model lacks the information, rewording the question cannot supply it. Prompt improvements plateau within the noise of a small test; supplying the missing document changes the result outright.

What to notice

62% → 66% → 68% → 67% with better prompts; 94% with the criteria document supplied. On 50 questions the standard error is about 7 points, so the prompt gains are within noise; the retrieval gain is not (Math Box 145.1).

Prompt-sensitive errors respond to rewording; knowledge gaps do not. Recognizing which you face saves effort: supply the source, use a tool, or fine-tune — not another round of phrasing (Chapters 27, 145–146).
