Supervised fine-tuning: only the answer is graded

In instruction tuning, the model sees prompt and response together, but the loss counts only the response tokens. It learns how to answer, not how to write questions.

What to notice

Response tokens with probabilities 0.40, 0.70, 0.90, 0.80 give losses 0.916, 0.357, 0.105, 0.223 — a mean of about 0.40 nats. The prompt’s “IOP” at 0.01 (loss 4.61) is not counted (Math Box 91.1).

Tick “count prompt tokens” and the loss is dominated by unpredictable prompt words the model should never be asked to produce. Masking focuses a small fine-tuning budget on behaviour (Chapters 91, 98).
