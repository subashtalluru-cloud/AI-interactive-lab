# Understanding Artificial Intelligence — Interactive Labs

128 interactive labs accompanying the 180-chapter textbook *Understanding Artificial Intelligence* (written for medical professionals). Each lab reproduces a worked example from the text and lets you change it.

## Open it
- **Online:** enable GitHub Pages for this repository (Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`). The site is at https://subashtalluru-cloud.github.io/AI-interactive-lab/, and every lab at `https://<user>.github.io/<repo>/<file>.html`.
- **Offline:** download and open `index.html` in any modern browser. No installation, no internet connection needed.

## Structure
- `index.html` — front page listing every lab with its chapters.
- `styles.css` — shared design (colours, typography, layout).
- `l*.html` — one self-contained HTML file per lab (vanilla JavaScript + SVG/canvas; no external libraries), all in the top folder next to `index.html`.

All links are relative, so the folder works the same on GitHub Pages, on any web server, or opened directly from disk.
