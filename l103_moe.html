Routing one token through a mixture of experts

A router scores every expert for this token; only the top few run, and their outputs are blended by renormalized router weights. All experts’ parameters exist; only a few do work per token.

Scale it up

What to notice

The book’s token: scores (1.2, 0.3, 2.0, −0.5) → probabilities (0.262, 0.107, 0.583, 0.048) → experts 3 and 1 with weights 0.69 and 0.31. With Mixtral-like settings, about 47B parameters are stored but about 13B are active per token.

Compute follows the active count; memory follows the total. An MoE is cheaper to run than a dense model of the same size but not smaller to hold (Chapter 103). Routers must also be trained to spread tokens across experts — otherwise a few popular experts do all the work and the rest waste memory.
