What a ten-point drop in error means

In 2012 AlexNet cut ImageNet top-5 error from 26.2% to 15.3%. Is a gap like that meaningful, or could it be chance? It depends on the size of the test set — and on the relative, not only the absolute, change.

What to notice

26.2% → 15.3% on 100,000 images: 26,200 → 15,300 errors, a 42% relative reduction; the standard error near 20% is about 0.13 points, so the 10.9-point gap is about eighty standard errors (Math Box 49.1).

Shrink the test set to a few hundred images — the size of many clinical validation studies — and the same gap is only a few standard errors. Small differences on small test sets are where overclaiming starts (Chapters 27, 49, 163).
