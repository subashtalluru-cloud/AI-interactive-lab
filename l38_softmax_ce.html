Softmax cross-entropy for one example

A classifier’s raw scores become probabilities through softmax; the loss is −ln of the probability given to the true class; the gradient on each score is simply probability minus target.

What to notice

Logits (2.0, 1.0, 0.1) → (0.659, 0.242, 0.099). True “no DR”: loss 0.417. True “severe”: loss 2.32 — a confident mistake — with gradient (0.659, 0.242, −0.901) (Math Box 38.1).

Add the same number to every logit: nothing changes, because softmax only sees differences. A language model does exactly this at every position, over a vocabulary of about a hundred thousand tokens (Chapters 38, 82–83).
