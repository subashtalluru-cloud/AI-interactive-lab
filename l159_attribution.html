Who gets the credit? Two attribution methods

An explanation method divides a prediction among the input features. For a linear model the division is exact. When features interact, there is no single obvious split — Shapley values choose the fair average over every order of adding features. Both answers depend on what “absent” means.

What to notice

The book’s cases: contributions 1.0, −0.6, 0.4 summing to the logit 0.8; Shapley values 3.5 and 2.5 summing to 6, with the interaction worth 1 split equally.

Move the baseline. Every attribution changes, though the model and the input have not: an explanation always answers “compared with what?” Set γ large and the credit each feature gets depends heavily on order — Shapley averages that away, but the average hides the interaction itself. Attributions describe the model, not the disease, and they need the sanity checks of Chapter 159 before anyone trusts them.
