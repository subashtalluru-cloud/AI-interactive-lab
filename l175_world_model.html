Planning inside a learned world model

A world model lets an agent try action sequences in imagination before acting. Candidate plans multiply with depth, and each predicted step carries a small chance of error — so long imagined plans drift from reality.

What to notice

3 actions, depth 2: 9 imagined sequences instead of 9 real trials. At 0.95 per step, a 2-step plan is sound with probability 0.90; a 10-step plan only 0.60 (Math Box 175.1).

Re-planning from real observations resets the error: the chance that each re-planned segment is sound depends only on the segment length. This is Chapter 9’s lesson again, and the same compounding as agents (Chapter 131) and autoregressive generation (Chapter 89).
