Superposition: more features than dimensions

A layer with two dimensions can still represent three features if they point in different directions and are rarely active together. The cost is interference when they are: each reads the others as noise.

What to notice

Three features at 120°: feature 1 alone reads back as (1, 0, 0) — perfect. Features 1 and 2 together read back as (0.5, 0.5, 0): both detected at half strength (Math Box 160.1).

If features are rarely active, collisions are rare and superposition is a good bargain — the model stores more concepts than it has neurons. It also means individual neurons respond to several unrelated features, which is why sparse autoencoders are used to pull the directions apart (Chapters 159–160, 178).
