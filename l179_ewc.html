Forgetting, and how to resist it

A model learned task A and now trains on task B. Plain fine-tuning slides the parameters wherever B wants — undoing A. Elastic weight consolidation adds a spring pulling each parameter back toward A’s solution, stiff where A cared and slack where it did not.

What to notice

With the book’s numbers — θ*_A = (1.0, 0.5), F = (10, 0.1), B preferring (0.2, −0.5) — plain fine-tuning goes all the way to B’s optimum. With λ = 1, θ₁ barely moves (to about 0.93) while θ₂ moves almost freely (to about −0.41): B is learned mostly in the parameter A did not need.

Too large a λ and B is never learned; too small and A is forgotten — the stability–plasticity trade-off. Replay, the other remedy of Math Box 179.1, keeps A’s real data in the mix instead, which works well but requires storing old data, often impossible for private clinical records (Chapter 179).
