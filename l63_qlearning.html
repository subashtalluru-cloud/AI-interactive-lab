Understanding Artificial Intelligence Chapters 58–63 · Lab L63.1

Q-learning on the corridor

Three states and a goal. Right from S2 reaches the goal with reward 1; everything else gives 0; γ = 0.9. The agent knows nothing about the corridor — it learns only from the steps it actually takes.

What to notice

In “always Right” mode, the first four episodes reproduce the book: Q(S2,R) = 0.5, 0.75, 0.875, 0.938; Q(S1,R) = 0, 0.225, 0.45, 0.619; Q(S0,R) = 0, 0, 0.101, 0.253. Value arrives at the goal first and flows backwards one state per episode.

Keep running and the values settle at 0.81, 0.9 and 1 — the Q* of Chapter 60 — with no knowledge of the transition rules. In ε-greedy mode the agent also learns what Left is worth (γ × the value of the state it lands in), which the always-Right agent never discovers. With ε = 0 from the start it may never find the goal at all: exploration is what lets it learn.
