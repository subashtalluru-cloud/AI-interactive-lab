The price of an informative code

A VAE’s encoder describes each input as a bell curve N(μ, σ²) in latent space. The KL term charges for how different that curve is from the prior N(0, 1). Move μ and σ and watch the bill.

What to notice

Case 1 costs nothing and says nothing: every input would get the same code. Case 2 costs 0.82 nats and identifies the input. Case 3 costs about 7 nats — pinning a code to a precise far-away point is expensive.

Both parts of the charge have a job. The μ part keeps codes near the origin, where sampling will look; the σ part stops codes collapsing to points, so the space between them is filled and decodes to something sensible. Training trades this bill against reconstruction quality (Chapter 110) — the same “stay near a reference unless the data justify moving” leash used in RLHF (Chapter 94).
