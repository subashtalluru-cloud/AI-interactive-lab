Why depth helps: parity

Parity asks whether an odd number of inputs are on. Flip any single input and the answer flips. A deep network computes it as a tree of XORs; a network with one hidden layer must carve out every region separately.

What to notice

n = 16: 15 XOR blocks in log₂16 = 4 levels, about 45 neurons in roughly 8 layers. A single hidden layer faces 2¹⁶ = 65,536 patterns in which every positive pattern’s neighbours are all negative (Math Box 41.1).

Representable is not the same as learnable: gradient descent finds parity notoriously hard even for networks that could compute it. Depth pays off when the problem has nested structure — as images, sound and language do (Chapters 22, 37, 41).
