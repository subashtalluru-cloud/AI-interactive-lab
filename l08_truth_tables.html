Truth tables: checking an argument by brute force

An argument is valid if no assignment of true and false makes every premise true and the conclusion false. A truth table checks every assignment — no insight needed, but the table doubles with every new atom.

What to notice

From “P → Q” and “Q” you cannot conclude P: the row P false, Q true makes both premises true and the conclusion false (Math Box 8.1).

Thirty atoms need about a billion rows; sixty need 10¹⁸. Logic is sound but brittle and expensive at scale — one reason AI moved toward probability and learning (Chapters 5, 8, 11). The clinical version of the fallacy: glaucoma causes cupping; this disc is cupped; so glaucoma — ignoring large physiological cups.
