A linear autoencoder rediscovers PCA

Squeeze 2-D points through a one-number bottleneck and reconstruct them. With a linear encoder and decoder, the best bottleneck direction is the first principal component: the direction along which the data vary most.

What to notice

At 45°, u = (0.707, 0.707). The point (−2, −1.8) encodes to z = −2.687 and decodes to (−1.90, −1.90); squared error 0.02. The one-number code keeps 99.6% of the variance (Math Box 109.1). “Find the best direction” lands at about 44° — for these four points the exact first principal component is a hair off the rounded (0.707, 0.707).

Rotate u to 135° and the reconstructions collapse to the origin — the code captures almost nothing. A nonlinear autoencoder can follow curved structure that no straight line can, which is what makes deep autoencoders, VAEs and latent diffusion possible (Chapters 18, 109–110, 113).
